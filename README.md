# advanced-algorithms-and-data-structures-playground

A Clojure sandbox for experimenting with advanced algorithms and data structures.

## Installation

Clone the repository and install dependencies via Leiningen.

```bash
lein deps
```

## Usage

Run the project entrypoint:

```bash
lein run
```

Build an executable uberjar:

```bash
lein uberjar
java -jar target/uberjar/advanced-algorithms-and-data-structures-playground-0.1.0-SNAPSHOT-standalone.jar
```
